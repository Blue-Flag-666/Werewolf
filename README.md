# 月隐 · 狼人杀法官助手

手机优先的真人狼人杀 Web 应用：单机法官、多人房间、十种角色、警长竞选、发言与投票、即时自爆/决斗、死亡连锁、人工裁定、代打、私人笔记及多视角复盘。React / TypeScript / Vite；联机使用 Cloudflare Workers + SQLite Durable Objects，两种模式共用规则引擎。

## 本地运行

需要 Node.js 22.12+（推荐 24）和 pnpm 11。

```sh
pnpm install
pnpm build
pnpm dev:worker
```

打开 `http://127.0.0.1:8787`，可使用单机与联机全部功能。前端热更新另开终端运行 `pnpm dev`，访问 Vite 给出的地址；其 `/api` 代理到 8787。单机不调用多人接口，首次成功加载后支持离线使用，浏览器支持时可安装为 PWA。

- 单机：配置版型 → 逐一查看并隐藏身份 → 法官开始首夜。存档保存在 IndexedDB；重新打开先遮挡。对局结束后可开始下一局，最多保留 10 局本机归档。
- 联机：法官创建房间，分享邀请链接或六位字母数字房间号；玩家加入并选座。法官保存版型，人数与连续座位匹配后发牌。刷新沿用本机会话，切勿公开会话存储内容。
- 代打：原玩家生成六位数字口令，观战者在 2 分钟内使用一次；原玩家或法官可撤销。撤销后立即停止发送新私有信息，但无法收回已看到的信息。私人笔记不随代打转移。

## 检查与测试

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm test:integration
pnpm exec playwright install chromium
pnpm test:browser
pnpm deploy:check
```

集成与浏览器测试自动选择空闲端口启动本地 Worker；集成测试另行重启进程验证已确认存档恢复；浏览器测试包含发牌、夜间操作、刷新遮挡、断网恢复、单机零多人接口请求及手机/平板/桌面主题检查。已安装 Chrome 时可设置 `BROWSER_CHANNEL=chrome` 代替下载 Chromium；PowerShell 写法为 `$env:BROWSER_CHANNEL='chrome'`。`TEST_URL` 可供直接执行测试脚本时指定已有服务器。`deploy:check` 只生成部署包，不实际部署。

## 部署到 Cloudflare

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/Blue-Flag-666/Werewolf)

按钮使用远程仓库内容；本次若仅交付本地文件，须由维护者将源码更新到目标仓库后使用。按钮流程会识别 `package.json` 的 build/deploy 命令。

手动部署：

```sh
pnpm exec wrangler login
pnpm deploy
```

`wrangler.jsonc` 已配置静态资源、SPA 回退、`ROOMS` 绑定及 `v1/new_sqlite_classes: ["Room"]` 迁移。首次部署自动创建 SQLite Durable Object 类；后续不要删除或改写已应用的迁移标签。可修改 Worker 名称，但已运行的房间与原命名空间绑定。

应用运行不需要额外 Secrets、D1、KV 或 R2。CLI 使用登录凭证；自动部署环境可单独配置 `CLOUDFLARE_API_TOKEN` 和 `CLOUDFLARE_ACCOUNT_ID`，不要写入源码。附带 CI 仅测试，不执行部署。

已按 2026-09-11 官方文档核实：免费计划可用 SQLite Durable Objects；当前包含 100,000 DO 请求/天、13,000 GB-s/天、5,000,000 行读取/天、100,000 行写入/天和总计 5 GB SQLite 存储，超额会失败。并非无限容量，Workers 本身也有独立配额。见 [计费](https://developers.cloudflare.com/durable-objects/platform/pricing/)、[限制](https://developers.cloudflare.com/durable-objects/platform/limits/)、[WebSocket 休眠](https://developers.cloudflare.com/durable-objects/best-practices/websockets/)和[部署按钮](https://developers.cloudflare.com/workers/platform/deploy-buttons/)。

## 关键默认规则与限制

- 支持平民、预言家、女巫、猎人、守卫、狼人、狼王、白狼王、骑士、白痴。可保存自定义版型；不实现丘比特等第三方技能，但支持最多 8 个独立第三方阵营、阵营裁定与优先级/共同胜利判断。
- 普通技能先提交，法官确认才生效；下一角色单独确认开始。狼人团队提交意向，由法官选定最终刀口。投票提交后不可自行改票，超时未投按弃票，正式结果仍需法官确认。
- 白狼王和骑士先发动、再限时选目标，目标直接结算。白狼王未选仍结束白天；骑士未选消耗次数、无效果恢复原流程。骑士失败/失效后重置原发言计时，非发言阶段不创建发言计时。成功杀狼或自爆结束白天后须法官确认入夜。
- 首夜实际中毒但尚未公布死亡的白狼王/骑士仍可发动公开技能，实际死亡者不能造成技能伤害，毒杀原始死因保留。隐藏死亡不会阻止警长报名和投票。入夜前需完成待公布死亡与死亡技能链。
- 默认女巫仅首夜可自救、不可同夜双药、解药用完不再看刀口；守卫可自守、不可连守，同守同救默认可救活；猎人/狼王中毒不可开枪，狼王自爆默认不带人。相关差异可配置。同一夜先处理狼刀（含守救），再处理毒药；首个有效死亡保留为原始死因，后续无效作用独立记录。
- 默认屠边，仅检测开局非空的好人分组；屠城目标阵营可设置。阵营变化后按当前阵营判断。胜利是法官确认建议，连锁未完成不判胜。复活不返还消耗或警徽，结束结论不会被静默覆盖。
- 白痴首次被放逐翻牌免死，失去后续放逐票权。警长放逐票默认 1.5；上警者不参与警长选举投票。平票支持 PK 重投或无人当选。自爆默认终止本次选举；关闭此设置时，在下一天重新开放报名。
- 无警长时按座位环随机选择死者起点和方向；平安夜随机合法发言者。遗言单独安排。临时表决不直接判死，并暂停原流程。
- 房主与法官权限独立。开局前长期离线 30 分钟释放座位，进行中保留角色与座位。房主离线 2 分钟后转移给在线成员，不赋予全知权；法官只能由现任法官明确授权给观战者，对方接受后接任。法官凭证全部丢失时没有任意接管后门。
- 每局 4–24 人，每房间最多 48 在线成员、64 连接、80 个保留会话。消息/请求体上限 16 KiB，每连接每 10 秒最多 30 条；加入密码每地址每 10 分钟最多 10 次；代打每 30 秒最多生成一次，每观战会话每 10 分钟最多验证 5 次。
- 每局最多 6,000 条事件，单房间快照最多约 150 万 UTF-16 字符，事务分块保存。远端保留最多 5 局归档，达到体积上限时优先淘汰最旧归档。全员离线且 7 天无活动后清理房间。笔记最多 20,000 字，仅主动勾选时随导出附加。
- 复盘显示公开、指定玩家当时及法官全知视角，默认结束后成员可看全知，可在开局关闭。结构化 JSON 标注格式版本和视角；旧格式不兼容会报错。

尚未验证真实 Cloudflare 账户部署、线上休眠计费及真机 PWA 安装；本地模拟器与浏览器测试不能替代这些线上验证。本项目不包含语音、聊天、AI 玩家、账号或公开匹配大厅。
